Two rendering choices

A Rust page with browser widgets

Askama renders the document. Gyral renders the components.

What happens on a request?

  1. Axum parses the page parameters in Rust.
  2. Askama renders HTML, including custom-element tags and escaped attributes.
  3. The browser loads the component bundle, registers the elements, and performs their first render.

The Rust server executes no JavaScript. These components use client rendering: there is no Gyral-rendered content for them to hydrate.

The other example in this repository embeds Gyral SSR through deno_core. It sends component contents immediately and hydrates them in the browser.

Keep essential content and ordinary forms in Askama when using this approach. Browser widgets become available after their JavaScript loads.
